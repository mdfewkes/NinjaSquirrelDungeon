# Legend of Shadowtail

A 2D action game where a ninja squirrel infiltrates a dungeon to retrieve a stolen magical acorn. Built with Godot 4.5.

## Running the Game

1. Open the project in [Godot 4.5](https://godotengine.org/download)
2. Press F5 to run

Or from command line:
```bash
godot --path .
```

## Controls

| Action | Keyboard | Gamepad |
|--------|----------|---------|
| Move | WASD / Arrows | Left Stick / D-Pad |
| Roll | K / Z | A |
| Katana | L / X | B |
| Shuriken | J / C | Y |
| Pause | P | Start |

## Project Structure

```
scenes/       Feature-organized scenes (Player, Enemies, UI, etc.)
code/         Shared reusable scripts
src/          Source assets (images, audio)
temp assets/  Placeholder assets
```
