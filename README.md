# Legend of Shadowtail

A 2D action game where a ninja squirrel infiltrates a dungeon to retrieve a stolen magical acorn. Built with Godot 4.5.

## Running the Game

1. Open the project in [Godot 4.5](https://godotengine.org/download)
2. Press F5 to run

Or from command line:
```bash
godot --path .
```

## Controls

| Action | Keyboard | Gamepad |
|--------|----------|---------|
| Move | WASD / Arrows | Left Stick / D-Pad |
| Roll | K / Z | A |
| Katana | L / X | B |
| Shuriken | J / C | Y |
| Tail Whip | V | X |
| Pause | P | Start |

(Note: we'll probably remove the "V" action in the future and make the tail whip swappable with one of the other actions)

## Project Structure

```
scenes/       Feature-organized scenes (Player, Enemies, UI, etc.)
code/         Shared reusable scripts
src/          Source assets (images, audio)
temp assets/  Placeholder assets
```

## Design Notes

## Backstory

A band of rodents has stolen the magic acorn that keeps your woodlands safe. To protect your woodland kin, you must venture into their sewer fortress and retrieve the acorn!

A single Zelda-like dungeon starting a squirrel ninja.

Acorns for health

Sample/recording based SFX

Prefer non-chiptune music
